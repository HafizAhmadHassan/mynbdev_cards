# My nbdev Cards

A Python library and documentation site built with **nbdev**, containing a collection of Jupyter notebooks organised as lessons, workshops, and practice sessions for programming education.

## Overview

Built with the nbdev workflow, the notebooks serve both as a Python package and as rendered documentation via Quarto. It is used as a teaching / practice resource.

## Repository Structure

```
├── nbs/           # Jupyter notebooks (lessons, workshops, practice)
├── mynbdev_cards/ # Generated Python package
└── site/          # Rendered Quarto documentation
```

## Tech Stack

Python, nbdev, Quarto, Jupyter, fastai.

## Status

Educational / teaching resource.
